**weibo-sociolinguistics-labeled-posts** 是微博社会语言学项目的博文级部分。每个研究日期，当天话题下采集的热门博文（去重前最多 200 条）由每日模型流程打标后发布在这里，一行一条博文。话题本身、总结与汇总计数见[话题总结](/zh/tech/datasets/weibo-topic-summaries)。

<p>
  <a class="btn btn--primary" href="https://huggingface.co/datasets/maikurokosmos/weibo-sociolinguistics-labeled-posts" target="_blank" rel="noopener">在 Hugging Face 查看数据集 ↗</a>
</p>

<Heading level={2}>1. 数据集基本信息</Heading>

- **来源**：每个研究日期选定的一个热搜话题下，微博给出的热门博文。
- **节奏**：每日更新（第一个研究日期：2026 Sept 28）。
- **规模**：目前已发布约 8,500 条，并在增加。
- **分析单位**：一行 = 一条博文，以 `record_key`（`YYYY-MM-DD::话题::NNN`）为键。
- **标注**：由模型生成，经过确定性的校验与清洗。人工复核单独发布在[每周人工复核](/zh/tech/datasets/weibo-weekly-label-reviews)，不会覆盖每日发布的数据。

<Heading level={2}>2. 标注字段</Heading>

每条博文带有以下结构化标签，取值沿用[之前微博语料库页面](/zh/tech/datasets/weibo-sociolinguistics)里的标注方案。

<div class="table-wrap">

| 字段 | 内容 |
|---|---|
| `validity` | 博文是否可用，不可用的话原因是什么。 |
| `target_type` | 博文主要谈论或指向的对象。 |
| `stance` | 对该对象的立场。 |
| `emotion_category` · `emotion_subtype` | 主导情绪及其细分。 |
| `mf_main` · `mf_direction` | 所涉及的道德基础及其方向。 |
| `satire` | 是否带有反讽或讽刺。 |
| `risk_score` | 确定性计算的分数，用来标出可能需要复查的标签。 |

</div>

<Callout type="conclusion" title="使用前请先读">
  标签由模型生成；博文来自微博对单个话题的热门排序，每天一个话题，因此不是微博的随机样本。完整字段、隐私说明与许可请看 Hugging Face 上的数据集说明。
</Callout>
