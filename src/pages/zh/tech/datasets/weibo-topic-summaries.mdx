**weibo-sociolinguistics-topic-summaries** 是微博社会语言学项目的话题级部分。每个研究日期选定一个微博热搜话题，本数据集为**每个日期保留一行**：话题本身、微博当时显示的话题指标、一段**由模型生成并经过脱敏的话题总结**，以及当天博文打标的**汇总计数**。它刻意**不发布单条博文正文、用户名或逐条诊断信息**。

配套的博文级数据见[微博社会语言学 · 博文标注](/zh/tech/datasets/weibo-labeled-posts)，人工复核单独放在[每周人工复核](/zh/tech/datasets/weibo-weekly-label-reviews)。

<Heading level={2}>1. 数据集基本信息</Heading>

- **来源**：每个研究日期选定的一个微博热搜话题。
- **节奏**：每日更新，按研究日期只追加（第一个研究日期：2026 Sept 28）。
- **分析单位**：一行 = 一个研究日期 / 话题。
- **语言**：中文。
- **格式**：单个累计 CSV，`data/topic_summaries.csv`，共 24 列，单一 `train` 划分。
- **许可**：发布者可控的总结、标注、文档与数据库编排部分采用 CC BY 4.0（见[许可与署名](#license)）。

<Heading level={2}>2. 数据是怎么生成的</Heading>

1. **记录当天热搜榜**并抓取话题指标。
2. **选定一个研究话题。**
3. **采集博文。**按页序遍历微博的「热门」结果，去重前最多 200 条。研究日期标识的是这一批次，并不按博文发布时间筛选。
4. **生成总结。**语言模型基于最多 20 条高互动博文和最多 20 条较长博文（不重复）写出话题级概述。
5. **博文打标**在另一个每日流程中完成，本数据集只收录汇总计数。
6. **脱敏并发布。**叙事字段经过确定性的公开文本处理，把手机号、身份证号、邮箱、URL、微博用户名和成对话题标签替换为占位符。

<Heading level={2}>3. 每一行包含什么</Heading>

<div class="table-wrap">

| 字段 | 内容 |
|---|---|
| `topic_key` | 稳定键，`YYYY-MM-DD::话题`。 |
| `date` | 研究日期。 |
| `topic` | 选定的微博话题文本。 |
| `selected_at` | 记录选题的 UTC 时间。 |
| `url` | 话题的来源链接。 |
| `read_count` · `discuss_count` · `interact_count` · `original_count` | 抓取时微博显示的话题阅读、讨论、互动、原创数。 |
| `description` | 微博自己的话题分类（不是生成的描述）。 |
| `metrics_captured_at` | 指标快照的 UTC 时间。 |
| `summary` | 模型生成、经过脱敏的话题总结。 |
| `summary_generated_at` · `summary_model` · `summary_prompt_version` · `summary_sampling_version` | 生成相关的元数据。 |
| `engagement_sample_count` · `longest_text_sample_count` | 用于生成总结的博文数量。 |
| `labeling_input_count` · `labeling_pass_count` · `labeling_cleaned_count` · `labeling_discarded_count` · `labeling_final_count` | 当天打标流程的汇总计数（`final = pass + cleaned`）。 |
| `labeling_discard_reason_counts_json` | 丢弃原因到数量的 JSON 映射。 |

</div>

<Heading level={2}>4. 局限与负责任的使用</Heading>

<Callout type="conclusion" title="使用前请先读">
  - **每天只有一个话题**，且从热搜中选出，因此不是微博的概率抽样。
  - **「热门」是微博在采集时给出的排序**，并非研究者计算的全局排名；采集时间、删帖与去重都会带来偏差。
  - **总结由模型生成**，可能不完整、不准确或带有文化局限。
  - **脱敏能降低风险，但不能保证匿名**：谐音、emoji 拼写、图片中的文字、具辨识度的公共事件都可能漏过。请勿用于识别、画像或联系任何个人。
</Callout>
